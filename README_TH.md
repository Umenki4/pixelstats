# Pixel Stats — ม็อดอัพสเตตัส RPG (Minecraft 1.20.1 Forge)

อัพ DEX / STR / CON / INT / LUC ได้ไม่จำกัด ทีละนิด ผ่านหน้าต่างสไตล์พิกเซล MMORPG มีเสียงเอฟเฟกต์
จ่ายด้วย **เลเวล XP ของ Minecraft** (1 เลเวล = 1 แต้ม) · เชื่อมกับ **Iron's Spells 'n Spellbooks** แบบไม่บังคับ

---
## 1) วิธี Build เป็นไฟล์ .jar (ทีละขั้น สำหรับคนไม่เขียนโค้ด)

**ต้องมี:** อินเทอร์เน็ต (ครั้งแรกโหลดไฟล์ราว 500 MB–1 GB) และ Java 17

1. **ติดตั้ง Java 17 (JDK)** — โหลด "Temurin 17 (LTS)" จาก https://adoptium.net  ตอนติดตั้งให้ติ๊ก
   *Add to PATH* และ *Set JAVA_HOME* ทั้งคู่
2. **แตกไฟล์ zip** ของโปรเจกต์ไว้ที่ที่ไม่มีภาษาไทย/ช่องว่างในชื่อโฟลเดอร์ เช่น `C:\mods\pixelstats-mod`
3. **เปิดหน้าต่างคำสั่ง ในโฟลเดอร์นั้น**
   - Windows: เปิดโฟลเดอร์ → คลิกช่อง address bar ด้านบน → พิมพ์ `cmd` → กด Enter
   - Mac/Linux: เปิด Terminal แล้ว `cd` เข้าโฟลเดอร์ จากนั้นพิมพ์ `chmod +x gradlew` หนึ่งครั้ง
4. **สั่ง Build**
   - Windows: `gradlew.bat build`
   - Mac/Linux: `./gradlew build`

   ครั้งแรกใช้เวลา **5–20 นาที** (โหลด Minecraft + Forge และถอดรหัส) ครั้งต่อไปจะเร็วขึ้นมาก
   ถ้าขึ้นว่า `BUILD SUCCESSFUL` แปลว่าสำเร็จ
5. **เอาไฟล์ที่ได้** อยู่ที่ `build/libs/pixelstats-1.0.0.jar`
6. **ติดตั้งเล่น**: ติดตั้ง Forge 1.20.1 (รุ่น 47.x) แล้วนำไฟล์ .jar ไปไว้ในโฟลเดอร์ `.minecraft/mods`
   (เซิร์ฟเวอร์ก็ใส่ในโฟลเดอร์ `mods` ของเซิร์ฟเวอร์ — **ต้องมีม็อดทั้งฝั่งผู้เล่นและเซิร์ฟเวอร์**)

**อยากลองเล่นเลยโดยไม่ต้องติดตั้ง Forge เอง:** `gradlew.bat runClient` (จะเปิดเกมทดสอบให้)

### ถ้าเจอ Error
- `JAVA_HOME is not set` / `Unsupported class file` → ติดตั้ง Java 17 ใหม่ตามข้อ 1 แล้วเปิดหน้าต่างคำสั่งใหม่
- `Could not resolve ...` / โหลดไม่ได้ → ตรวจอินเทอร์เน็ต/ปิด VPN แล้วสั่งใหม่
- ลองล้างแล้วสั่งใหม่: `gradlew.bat --stop` แล้ว `gradlew.bat clean build`
- ถ้ายังไม่ได้ **ก๊อปข้อความสีแดงทั้งหมดส่งกลับมา** (ดูได้ที่ท้ายข้อความ หรือเพิ่ม `--stacktrace`)

## 2) วิธีเล่น

- กดปุ่ม **K** เปิดหน้าต่างสถานะ (เปลี่ยนปุ่มได้ที่ Options → Controls → Pixel Stats)
- กดปุ่ม **+** ข้างสเตตัสที่ต้องการ = จ่าย 1 เลเวล XP ได้ +1 แต้ม (**Shift+คลิก = ซื้อสูงสุด 10 แต้ม** เท่าที่เลเวลพอ)
- เอาเมาส์ชี้แถวสเตตัสเพื่อดู tooltip รายละเอียดผลทั้งหมด
- โหมด Creative อัพฟรี (ปิดได้ใน config)
- แต้มที่อัพไม่หายเมื่อตาย (ปิดได้ใน config)

| สเตตัส | ผลที่ได้ (ค่าเริ่มต้น) |
|---|---|
| **DEX** | โอกาสหลบการโจมตี `50%·p/(p+150)` · ดาเมจอาวุธระยะไกล +0.5%/แต้ม · ความเร็วเดิน `30%·p/(p+300)` |
| **STR** | ดาเมจระยะใกล้ +0.05/แต้ม · เลือดสูงสุด +0.1/แต้ม |
| **CON** | เลือดสูงสุด +0.25/แต้ม · รีเลือด +0.01 HP/2 วิ ต่อแต้ม · ต้านสถานะร้าย `60%·p/(p+200)` · ต้านแรงกระแทก |
| **INT** | (Iron's Spells) พลังเวท +1%/แต้ม · มานาสูงสุด +2/แต้ม · รีมานา +1%/แต้ม |
| **LUC** | โอกาสคริติคอลทั้งระยะใกล้และไกล `60%·p/(p+120)` (คริ = ดาเมจ ×1.5) |

`p` = แต้มที่ลง สูตรแบบ "เปอร์เซ็นต์โอกาส" อัพได้เรื่อยๆ แต่จะไม่ถึงเพดานเต็มๆ (เช่น DEX 100 แต้ม ≈ หลบ 20%, LUC 100 แต้ม ≈ คริ 27%)
จึงเล่นได้ไม่มีวันหมดแต่ไม่พังบาลานซ์ · INT ต้องมี Iron's Spells 'n Spellbooks จึงจะมีผล (ไม่มีก็เล่นได้ปกติ)

## 3) คำสั่งทดสอบ (ต้องเป็น OP / เปิด Cheats)
เล่นเดี่ยว: ตอนสร้างโลกเลือก *Allow Cheats: ON* หรือ Esc → *Open to LAN* → *Allow Cheats* · ใช้ `/ps` แทน `/pixelstats` ได้

| คำสั่ง | ความหมาย |
|---|---|
| `/pixelstats givelevels @s 50` | **เสกแต้ม**: ให้เลเวล XP 50 เลเวล (= 50 แต้มอัพ) |
| `/pixelstats add @s DEX 20` | เพิ่มสเตตัสตรงๆ |
| `/pixelstats remove @s STR 5` | **ลดสเตตัสที่เผลออัพ** |
| `/pixelstats set @s CON 100` | ตั้งค่าตรงๆ |
| `/pixelstats reset @s` | รีเซ็ตทุกสเตตัสเป็น 0 |
| `/pixelstats reset @s LUC` | รีเซ็ตเฉพาะ LUC |
| `/pixelstats info` | ดูแต้มของตัวเอง (`/pixelstats info <ชื่อ>` ดูของคนอื่น) |

> หมายเหตุ: `remove/set/reset` ลดแต้ม "ไม่คืน" เลเวล XP ให้ — ถ้าอยากได้คืนใช้ `givelevels`

## 4) ปรับสมดุลค่าต่างๆ (config)
ไฟล์ `pixelstats-server.toml` อยู่ที่ `saves/<ชื่อโลก>/serverconfig/` (เซิร์ฟเวอร์: `world/serverconfig/`)
แก้ราคาอัพ (`levelCostPerUpgrade`), ค่าต่อแต้มของทุกสเตตัส, เพดานโอกาส, ปิด/เปิดอัพฟรีใน Creative, เก็บแต้มตอนตาย ฯลฯ
แก้ตอนปิดเกมก่อนจะปลอดภัยที่สุด (เซิร์ฟเวอร์จะซิงก์ค่าไปให้ผู้เล่นเอง)

---
## 5) ความเข้ากันได้ / การทำงาน
- ค่าสถานะใช้ **Attribute Modifier ของ Minecraft** (ดาเมจ, เลือด, ความเร็ว) จึงทำงานร่วมกับม็อดต่อสู้/ของอย่าง Epic Fight, Apotheosis, Relics ที่อ่านค่า attribute ได้ตามปกติ
- INT หา attribute ของ Iron's Spells ด้วยชื่อ (`irons_spellbooks:spell_power / max_mana / mana_regen`) ตอนรันเกม — ไม่มี Iron's Spells ก็ไม่ crash
- เซิร์ฟเวอร์เป็นคนตัดสินทุกอย่าง (หักเลเวล, เพิ่มแต้ม) ไคลเอนต์แค่ขอ จึงโกงด้วยแพ็กเก็ตปลอมไม่ได้
- ไม่มีบล็อก/ไอเท็มใหม่ จึงไม่มีไฟล์โมเดล 3D (มีเฉพาะเท็กเจอร์ UI และเสียง)

## 6) โครงสร้างโปรเจกต์
```
src/main/java/com/pixelstats/   โค้ดทั้งหมด (stats / events / network / command / client / config / registry)
src/main/resources/assets/pixelstats/
    textures/gui/               เท็กเจอร์พิกเซล (panel, row, banner, button, ไอคอน)
    sounds/ + sounds.json       เสียงเอฟเฟกต์ .ogg
    lang/en_us.json, th_th.json ภาษาอังกฤษ/ไทย
tools/generate_assets.py        สคริปต์ที่สร้างเท็กเจอร์+เสียงทั้งหมด (แก้แล้วรันใหม่ได้)
```
เท็กเจอร์และเสียงทั้งหมดสร้างขึ้นเองด้วยสคริปต์ จึงไม่มีปัญหาลิขสิทธิ์ · โค้ดเขียนขึ้นใหม่ทั้งหมด ไม่ได้คัดลอกจากม็อดอื่น
